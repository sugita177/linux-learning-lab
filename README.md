# linux-learning-lab

Webエンジニアの実務に直結する Linux コマンドおよびシェルスクリプトの実践ハンズオン用リポジトリです。

## 目的と背景

基本的な Linux コマンドや Web 開発（PHP 等）の基礎知識をベースに、実務で直面する以下の3つの具体的な場面に特化して実践的なスキルを習得します。

1. **サーバー内での実務操作**
   - 本番・検証環境での大規模ログ解析、障害調査、リソースボトルネック（CPU / メモリ / ディスク / ネットワーク）の特定
2. **GitHub Actions の Workflow 構築**
   - エラーハンドリング、ステップ間出力連携、壊れにくく保守しやすい CI/CD シェルスクリプトの作成
3. **AI エージェントが使用する Bash 操作**
   - 非対話（Non-interactive）コマンドの徹底、標準入出力の厳密な制御、`diff` / `patch` による安全なコード更新、構造化データの連携

## 学習環境

- **ホストOS**: macOS
- **実行環境**: OrbStack 上の Docker コンテナ（Ubuntu）
  - ホスト OS（macOS / BSD 系コマンド環境）に副作用を与えず、本番サーバーで主流の GNU/Linux 環境で安全に実験・検証を行います。
- **エディタ**: Antigravity IDE

## 学習の進め方

1. [road_map.md](road_map.md) に記載されたカリキュラムに沿って、1トピックずつ対話型ハンズオン形式で進めます。
2. メンター（AI）から課題のゴールと着眼点・ヒントが提示されます。
3. Docker（Ubuntu）環境上で実際にコマンドやスクリプトを試行し、実行コマンドと出力結果を共有します。
4. エッジケース、セキュリティ、パフォーマンス、副作用の観点からレビューを受け、改善・定着を図ります。
